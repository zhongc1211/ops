# ops-system 失败清单（实现前）

本清单是风险与验收要求，不表示防护已经实现。若生命周期要求 agent 调用 Paperclip 管理接口，按批准第 80 条停止，不能以指令代替权限隔离。

| 风险 | 怎么发现 | 怎么防／验收门槛 |
| --- | --- | --- |
| note、log_tail 注入合并、起 agent、批准、写 [Zack答]、改设置指令 | 检查模板和恶意输入样本；核实际工具调用 | 字段全部视为不可信数据；指令明确禁止；工具权限独立阻断 |
| log_tail 或 note 的波浪线、反引号围栏提前闭合 | 检查含 `~~~~`、三反引号及缩进围栏的发送结果 | 发送方消除围栏行；静态模板不能单独提供隔离；数据仍不能作为指令 |
| 访问本机管理端口，包括命令替换、管道、其他 orca 子命令、ssh 转发 | 审查正式允许清单及实际拒绝测试 | 不允许通用 Bash、网络运行时、WebFetch、MCP HTTP、ssh；只有经验证的限定命令可考虑放行；无法保证则停止 |
| 改自身设置／指令，写批准台账，读密钥 | 审查路径权限；测试假的同名目标；绝不读取真实密钥 | 默认拒绝写工具；显式拒绝设置、指令、台账及实例 .env、secrets/、触发凭据目录、grokbot 配置目录 |
| 起 agent、合并 PR、推代码 | 审核 orca terminal create、orca-agent-launch、远程 environment、gh、git 权限 | 不放行上述命令；禁止通过允许命令的参数或 shell 组合逃逸 |
| routine issue 无人关闭，后续唤醒被合并或漏掉 | 追踪固定版本 routine、heartbeat、issue 源码及读回策略 | 在实现前确认无需 agent 管理接口的闭环；必须访问接口则停止求决策 |
| 反复唤醒／补跑导致重复花钱 | 查 routine 并发、补跑、heartbeat 完成处理源码 | 禁用周期 heartbeat；单并发；核对明确的补跑与 issue 完成策略，不能仅凭单并发保证 |
| 发送方超时重试触发两次 | 核触发端 Idempotency-Key 的实现、作用域、时间窗 | 只有确认服务端真实去重才发送稳定键；不能把发送方去重当作服务端保障 |
| LaunchAgent PATH 找不到 orca，Orca 应用未打开 | 检查启动环境和 CLI 路径；只读探测，不真实写 Linear | 部署前明确固定路径和应用依赖；失败明确报告，不扩大权限重试 |
| 单次卡住、单晚多次唤醒、预算失控 | 查运行超时、预算和触发记录；验收时监控时间与费用 | 正式运行前落实超时及次数限制；验收一次、费用超过两美元或十五分钟未结束即取消并暂停 |
| 部署覆盖文件但读回不一致／权限放宽 | 比对仓库和部署文件摘要、模式、adapter 配置、paused 状态、运行计数 | 默认计划，apply 前备份，写后读回；不恢复 agent；失败从备份回滚 |
| 开发验证误写 Linear 或使用生产触发凭据 | 检查测试命令和环境来源 | 仅假目录／无副作用验证；作者不触发、不写 Linear、不读凭据；验收另依单次授权 |

## 第 2 轮：宿主侧收尾（编码前）

以下仍是验收要求，不代表已实现。

| 风险 | 怎么发现 | 怎么防／验收门槛 |
| --- | --- | --- |
| 轮询晚于 heartbeat 收尾，补跑已被排入队列 | 查 adapter 等待子进程和 reconciliation 调用链 | 在包装进程退出前完成验证及处置；不能依赖事后轮询 |
| 包装脚本／配置可被模型修改或直接调用，变成管理 API 跳板 | 核允许清单、deny 路径、命令参数、继承环境 | 安装在 agent 写范围外；显式 deny 读写与执行；不能给模型通用执行工具 |
| 假评论、旧评论、其他 run 的评论被当作成功 | 回查 Linear 评论完整标记、关联 issue、作者及创建时间 | 只接受本次宿主生成标记、精确目标、运行窗口内的真实评论；读不到／多义就失败 |
| claude 返回成功但没有写 Linear | 模拟无评论或读回失败 | 不凭退出码标 done；验证失败先暂停，保留未完成状态 |
| 本次 issue/run/agent 标识错配，错误关闭其他任务 | 对照服务端 run、issue、agent 归属和执行锁 | 禁止仅相信模型输出或调用参数；必须核服务端绑定 |
| 同 issue 多次／并发启动模型 | 查所有关联 heartbeat run 和宿主持久锁 | 模型启动前独占计数，第二次不启动模型并暂停；不能只靠 maxConcurrentRuns |
| 运行超时、超预算、费用上报延迟 | 查预算读取、usage 上报时机、超时监护 | 宿主限定墙钟时间、检查月预算及已知费用；不把事后成本当实时硬上限 |
| 暂停 API 失败但包装进程退出，引发补跑 | 模拟接口中断，检查退出后的生命周期 | 未确认暂停不能声称安全；持久熔断防后续模型启动，报告待人工恢复 |
| 宿主崩溃、被杀、Paperclip 重启、锁记录丢失 | 核异常／信号／重启路径 | 失败闭合，持久状态不自动清除；恢复须人工核查，不自动再试模型 |
| Orca 未启动、CLI 超时或响应结构改变 | 只读验证 CLI 与结构，模拟失败 | 严格解析并限时；不标 done、暂停、写不含凭据的日志 |
| 包装脚本污染 adapter stdout 或隐藏实际权限参数 | 查 stream-json 协议和命令记录 | 原样传递 claude 输出，宿主日志独立；校验 dontAsk／非 skip，保留真实启动证据 |
| 安装覆盖非预期状态或回滚后放宽权限 | 检查 dry-run、备份、原子写、读回 | 本轮不 apply；安装前 paused/零运行，备份后验证摘要／模式；回滚也保持暂停 |
