## superpowers：仅 launcher 的 Claude 会话

`wake/bin/orca-agent-launch` 仍 exec notify-run，Claude 仍是 notify-run 的直接子进程；不改 notify-run 或 orca-wake。核过 #83 的文件列表，没有改 orca-agent-launch。

只在 agent basename 为 `claude` 时，将 `enabledPlugins["superpowers@claude-plugins-official"]` 设为 false，通过一个 `--settings` 传入。iMac 只读确认启用的就是这个键、版本 7.0.0；MBA 的键待验收方核对，若不同不要宣称已禁用。pi/codex 参数不变，Zack 直接起 claude 的会话不经过本入口，不受影响。

已有 `--settings FILE`、`--settings JSON`、`--settings=...` 合并保留其他字段；重复 --settings 拒绝，不猜覆盖顺序；`--` 后作为提示词原样保留。JSON 解析失败不输出内容。最终设置固定放进 `/tmp/orca-claude-settings.XXXXXX`，权限 0600，**不再使用可指向永久目录的 TMPDIR**，不把原设置内容展开到 argv/dry-run/日志；dry-run 和启动前拒绝时自动删除。成功 exec 不执行 EXIT trap，回收交给 macOS 自带的 `com.apple.tmp_cleaner`：iMac 只读核过系统 plist，每日零点运行 `/usr/libexec/tmp_cleaner`；man page 明确清理 /tmp 中近期未修改的内容。**不是会话结束即删，也不承诺某个小时内删完**，休眠、系统清理停用、持续访问可能延后。会话结束后可按打印的确切路径提前删除；不在运行期间删，不用通配符删别人文件。该文件可能含原设置敏感值，不能归档。MBA 系统清理任务仍须安装方核；非 macOS 主机没有本轮核实的系统回收保证。

选系统延迟清理而不加包装进程/旁路守护器，是为了保持 notify-run exec 的 Claude 直接子进程关系，也不修改被禁止的 notify-run。没有可靠的「Claude 已读完且不会重读」确认，不能 sleep 若干秒就删除文件。本轮不手动启动 tmp_cleaner、不改系统任务；只核其文档/配置和本轮临时文件路径权限。

理由：官方 [CLI reference](https://code.claude.com/docs/en/cli-reference) 的 --settings 是会话覆盖，未指定键保留文件值；不必全局禁用、不必关闭全部插件、不必复制整个 ~/.claude。managed policy、显式 --plugin-dir 重新加载 superpowers 等不在这个覆盖能保证的范围内；不要拿本方案当对抗恶意调用方的安全沙箱。是否实际不加载仍待真实会话验证。

S12 ③ 的 #83 使用自己生成的权限 settings，不经这个 launcher 起 ops-system；`provision.py:34–39` 的 extraArgs 是 `--bare --permission-mode dontAsk --permission-prompts none --settings <AGENT_SETTINGS>`。`--bare` 不加载用户插件/skills，因此本轮 CE Skill deny 和用户插件钉版不会改变它的插件加载；其独立 settings 文件也不在安装器写入路径。不能把 --bare 说成忽略所有用户权限设置。本轮不改该 PR 的文件、现网设置或 Paperclip。只读代码核对不是运行验收。

## 两台安装步骤（只交步骤，不执行）

每台分别获得批准后做；先 iMac，验收读回成功后再申请 MBA。不要在现网主检出 pull/checkout。从**验收过的完整 PR sha**导出到专用目录，确认脚本是该 sha；别用移动的分支名安装。以下在目标机本地终端执行，不从本作者会话 ssh MBA。

1. 运行 `date`；iMac 先 `sysctl -n kern.memorystatus_level`，低于 25 停；起验收会话还须主会话按 R9 审批。设置超时程序：iMac `T=/usr/local/bin/timeout`，MBA `T=/opt/homebrew/bin/timeout`。以下每条操作用 `"$T" 840` 包住。
2. 只读当前版本，不运行模型：用 python3 读取 `~/.claude/plugins/installed_plugins.json`，对三个插件仅打印键名、version、gitCommitSha；不要输出其他用户设置。另对两个 pinned-marketplaces 做 `git rev-parse HEAD`。运行 `bash <导出目录>/bootstrap/claude-plugins/pin-claude-plugins.sh --check`，保留非零输出作为改前基线。
3. 备份：`umask 077`，用 `mktemp -d "$HOME/ops-archive/claude-plugins-backup.XXXXXX"` 建目录，将 `settings.json`、`CLAUDE.md`、`plugins/`、`pinned-marketplaces/`、`hooks/` 中现有的项逐个 `cp -pR` 过去，记录哪些原本不存在；还备份实际 `command -v orca-agent-launch` 指向的已装脚本。备份成功才继续。不要打开凭据文件；备份目录仅本人可读，不推 Git。用 `shasum -a 256` 记录上述配置文件及已装 launcher 的校验和。
4. iMac CE 需要重装，不是普通同版本 update：先在批准范围内运行 `claude plugin uninstall --scope user compound-engineering@compound-engineering-plugin`，再跑下面 pin。若卸载失败停，不手工删除缓存。MBA 先读回；CE 不是钉版时同样重装，已经准确匹配时不必卸载。pstack 若 update 后仍读回不符，同样停下报告，不把失败当成功。
5. 确保没有别的安装器同时写 settings；清除或确认 `CLAUDE_CONFIG_DIR` 指向默认目录，执行 `bash <导出目录>/bootstrap/claude-plugins/pin-claude-plugins.sh`。此脚本会克隆指定 commit、合并现有 JSON、写前备份、安装 deny/hook、更新插件并最终 check；任一失败立即停止，不继续安装另一台。不要用此脚本覆盖整份 settings。
6. 在同一次该机安装授权包含 launcher 更新时，把导出目录的 `wake/bin/orca-agent-launch` 装到第 3 步记录的实际落点（先备份、比 diff，再 `install -m 755`）；不要安装 notify-run、orca-wake。如果当前落点不是普通独立文件或和已核版本不同，停交主会话定，不跟随未知软链覆盖。
7. 读回 `pin-claude-plugins.sh --check` 必须 0；确认安装记录和实际 installPath 的插件 manifest 均为 0.15.29 / 3.31.0，commit 分别匹配上面的完整 sha，marketplaces 为 directory 源且 autoUpdate false；逐条比对 fragment 的 29 条 deny，ce-code-review、ce-noslop 不在其中；确认用户 superpowers enabledPlugins 未改变；对比备份 JSON，仅允许预期键变化，现有其他设置保留；launcher 文件 hash 应与验收 sha 导出文件一致。
8. 10-30 以后按下节跑实际新会话：旧会话不会因文件安装自动刷新。失败不判安装验收通过。

### 回退

- 不以卸载 deny 代替完整回退：`install.sh --uninstall` 只撤 29 条新格式 deny 和本功能 hooks，不撤旧 10 条、不恢复插件版本。
- 在确认无并发设置写入、无依赖该临时配置的会话后，恢复备份的 settings.json、CLAUDE.md、plugins、pinned-marketplaces、hooks，以及已装 launcher；先把安装后的对应项移到单独保留目录，再 `cp -pR` 恢复，不能只把目录叠拷而留下新文件。原来不存在的项移出后不恢复。逐项核备份 hash，并用原来版本的检查命令读回。若期间有别人改设置，停止，人工合并，不能用旧备份覆盖。
- launcher 成功会话的临时 settings 只在该会话结束后按具体路径删除。
- 代码合并后如需整体撤回，用 main 上实际合并方式对应的 revert，交主会话确认；不要照搬旧 PR 的提交序列来撤当前分支。
- 历史 PER-89 交接提出的 `git revert 20ef768 62de7d5 && git revert -m 2 074da91` 只是撤当时 PER-89 的候选命令，不适用于本轮合入 main 后的整体回退；本轮若未实测，就必须标没跑。
