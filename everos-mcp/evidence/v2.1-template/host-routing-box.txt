## Verdict
nginx chooses the server block by local address:port FIRST, then by Host among blocks on that address. A connection that
arrives on 100.64.0.5:80 only considers everos-tailnet.conf (the only block with that exact address), so ANY Host works:
Host 100.64.0.5, everos.deepvision.sg and random.invalid all returned 200 with the same 3 episodes. If it had fallen to the
default server we would have seen 444 (connection closed, empty reply), not 200 + data.
It can reach the public blocks only if everos-tailnet.conf is removed/disabled. Then:
  Host: 100.64.0.5           -> default_server -> 444 (fails closed, no data, MCP sees "unavailable")
  Host: everos.deepvision.sg -> public everos.deepvision.sg block -> still works (same auth map)
So xinyue's MCP traffic (Host 100.64.0.5) is safe today only because of the tailnet server block; sending
Host: everos.deepvision.sg explicitly makes it independent of that block. v2.1 does this on every request.
