# 要上生产的改动，PR 直接从 feat/xinyue-site 切

**规则：** 准备上生产的改动，每个 PR 以 `feat/xinyue-site` 为 base、一款游戏一个 PR，不叠在别的未合并 PR 或 testing 分支上。

Seen 1×（2026-10-13）

## 出了什么事

- #61、#62、#63 互相叠着开（#62 的 base 是 #61 的分支，#63 的 base 是 #62 的分支）；#64、#65、#67 的 base 是 `zhongc1211/testing-games-1012`。
- 10-13 要把涨水逃生和大嘴洞洞上生产、摇摇荡荡先不上时，这些 PR 都不能直接合。#61、#63、#64、#65 被关掉，内容重新切成 #68–#71。#69 的正文写明要「去掉与摇摇荡荡纠缠的部分」。
- #67 改 base 到 `feat/xinyue-site` 后是 2422 行，超过 2000 行上限，又把 2D 部分拆成 #73（1654 行），#62 关闭。
- 后果：同一批内容开了两轮 PR（关掉 5 个，新开 5 个），共用文件里的条目要手工重新分拣。
