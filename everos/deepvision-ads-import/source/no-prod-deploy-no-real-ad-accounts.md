# 不部署生产、不用真实广告账户、不花钱

**规则：** 不部署生产（ads.deepvision.sg、main），只用 Google Ads 测试账户和 Meta sandbox 广告账户，不接真实支付，不做任何花钱的事。

Seen 1×（2026-10-12）

## 怎么做

- Buy / Subscribe 按钮在 testing 只走到「确认弹窗 → 提示支付未开通」。
- 要动生产或花钱，先停下来问 Zack，等批准。
