# Orca 工作区名里不要带「/」

**规则：** 工作区名（显示名）里不要带「/」：2026-10-12 23:49，队列启动 FDV-51 时失败，原因是名称里的「/」弄坏了启动脚本。

Seen 1×（2026-10-12）

## 怎么做

- 显示名按「dv广告 · FDV-xx 简述」命名，简述里用「、」或空格，不用「/」。
